# ⚓ Neural Armada: AI-Assisted Naval Tactics

> **Project Goal:** A 2D top-down naval combat simulator developed to demonstrate the exhaustive integration of AI tools across the entire Software Development Life Cycle (SDLC), from ideation and coding to CI/CD pipelines and automated testing.

## 📖 Project Overview
*Neural Armada* is a scaled-down tactical naval game inspired by *Battle Fleet 2*. The core focus of this repository is not just the game itself, but the **AI-driven development process**. The game features two strictly locally-run AI agents that actively influence the gameplay loop.

---

## 🤖 In-Game AI Agents
To meet the core implementation requirements, this project integrates two Local LLMs (e.g., via Ollama using `phi3` or `qwen`):

1. **Agent 1 (The Enemy Admiral):** Analyzes the player's current fleet status and outputs JSON-formatted tactical decisions (e.g., spawn coordinates, target prioritization, retreat logic).
2. **Agent 2 (The Deck Officer):** Acts as the dynamic narrator. It receives event triggers (e.g., "ship took 50 damage") and generates immersive, in-character status reports and warnings displayed on the UI.

## 👥 Team Roles & Task Division

Our team of 5 is structured to ensure every rubric requirement (Agile, Git, Tests, CI/CD, Evals) is met comprehensively. **Note: Every member is required to have a minimum of 5 commits on this repository.**

### 1. 🛠️ Lead Engine Developer (Core Gameplay)
* **Focus:** Game loop, physics, and rendering.
* **Responsibilities:**
  * Setup the base game engine (Python/Pygame or Godot) using AI coding assistants (Cursor/Copilot).
  * Implement ship movement, aiming, and basic collision detection.
  * **Rubric task:** Record the final offline gameplay screencast for the demo presentation.

### 2. 🧠 AI Architect (Tactical Agent Integration)
* **Focus:** LLM integration and JSON parsing.
* **Responsibilities:**
  * Setup the local LLM API pipeline.
  * Prompt engineer **Agent 1 (Enemy Admiral)** to ensure consistent, parsable JSON outputs for the game engine.
  * **Rubric task:** Ensure the Agent 1 branch is properly merged via Pull Request.

### 3. 🎨 Tech Artist & Narrative AI (Narrator Agent)
* **Focus:** Visuals, UI, and dynamic text.
* **Responsibilities:**
  * Generate 2D game assets (ships, water textures) using AI image generators.
  * Integrate **Agent 2 (Deck Officer)** and build the UI text-box system to display its outputs.
  * **Rubric task:** Document the AI prompts used for asset generation in the final AI Report.

### 4. ⚙️ QA & DevOps Engineer (Testing & Pipelines)
* **Focus:** CI/CD, automated testing, and issue tracking.
* **Responsibilities:**
  * Use AI to write automated unit tests for game logic (e.g., `pytest`).
  * Implement **AI Evals** (scripts to test if the local LLMs output valid formats/tones).
  * **Rubric task:** Create the `.github/workflows` CI/CD pipeline.
  * **Rubric task:** Simulate a Bug Report via GitHub Issues and resolve it via a linked Pull Request.

### 5. 📋 Scrum Master & Tech Writer (Agile & Documentation)
* **Focus:** Project management, diagrams, and rubric compliance.
* **Responsibilities:**
  * Generate and manage the 10+ Agile User Stories in the Backlog.
  * Use AI to generate Mermaid.js/UML architecture diagrams.
  * **Rubric task:** Compile the final `AI_TOOLS_REPORT.md` detailing the time saved and prompts used across all development phases.
